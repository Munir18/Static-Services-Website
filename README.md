# MediaK9 Studio

A modern, responsive business website developed for **MediaK9 Studio**, showcasing digital marketing and creative services. The project is built using HTML, CSS, JavaScript, and PHP, with a focus on clean design, performance, and user experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern landing page
- Service pages
- Portfolio / Work showcase
- Studio page
- Contact page
- PHP contact form with email functionality
- Reusable header and footer components
- SEO-friendly structure
- Fast loading static website

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- Font Awesome
- Google Fonts

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Munir18/Static-Services-Website.git
```

### Open the project

Simply open `index.html` in your browser.

For the contact form, run the project on a local server such as:

- XAMPP
- WAMP
- Laragon
- Local by Flywheel (optional)

Example:

```
http://localhost/Static-Services-Website/
```

## 📧 Contact Form

The project includes a PHP mail handler (`send-mail.php`).

Before deploying:

- Configure your SMTP settings or mail service.
- Never commit passwords or API keys to GitHub.
- Store sensitive credentials in environment variables or a `.env` file.
